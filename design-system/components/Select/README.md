# Select

A labelled native select for the category page's Filter and Sort controls.

**Consumer provides:** `label` (shown before the field, e.g. “Filter:”), `options` (strings or `{value,label}`), and native select props (`value`, `onChange`, `defaultValue`).

- Keep it native for keyboard and mobile support; the chevron is decorative.
- Right-align Filter and Sort on the same line as the section heading.
