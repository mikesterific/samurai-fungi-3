# SectionHeading

A serif section title with the forest brush stroke beneath it, plus optional eyebrow and italic lede.

**Consumer provides:** `title`, optional `size` (`xl` hero, `display`, `l` section default, `m` sub-section), `eyebrow`, `lede`, `align` (`left` | `center`), `as` (heading tag), `brush` (false to drop the stroke), `tone="band"` on ink bands.

- Every section on Home, Category and Product opens with one: “Shop Extracts”, “Why Ours”, “What's Inside”.
- One `xl` per page. Titles in Title Case, no trailing period (band titles may end in one for emphasis).
