# ProductSummary

The product buy box: name, italic product line, brush stroke, tagline, large price, quantity + Add to cart, and the trust badge row.

**Consumer provides:** `name`, `price`, optional `subtitle`, `tagline`, `features` (`FeatureRow` items), `ctaLabel`, `onAddToCart(quantity)`.

- Sits right of `ProductGallery` in a two-column layout; stacks below it on mobile.
