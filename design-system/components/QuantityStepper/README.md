# QuantityStepper

The − 1 + quantity control that sits beside Add to cart.

**Consumer provides:** `value` + `onChange` (controlled) or `defaultValue`; optional `min` (1), `max` (99), `label` (accessible name, default “Quantity”).

- Same 52px height as a `lg` Button; place it left of the button with `space-4` between.
- The minus/plus disable at the limits; don't hide them.
