# ProductCard

Storefront product tile: bottle photo, name, product line, price and a View Product button.

**Consumer provides:** `image`, `name`, `price` (number, formatted USD, or a string), optional `subtitle` (“Ultrasound Dual-Extract”, “Mushroom Blend”), `href`, `ctaLabel`, `soldOut`.

- Four across on desktop with a `space-4`–`space-6` gutter.
- Photograph every product the same way: amber bottle centred, the mushroom around it, forest floor behind.
- Sold out shows the word “Sold out” in `danger` and an outline button; never colour alone.
