# FeatureRow

A row of icon-over-label trust badges divided by hairlines (Fruiting Bodies Only · Ultrasound Extraction · Dual Extract · Small-Batch Crafted).

**Consumer provides:** `items` (`{icon, label}`, 3–4 items), optional `iconSize` (default 40), `tone="band"` on ink bands.

- Labels are two short words, Title Case, no punctuation.
- Use it under the buy box on product pages and inside the UAE band on category pages.
