# CategoryCard

Homepage category tile: photo, line icon, serif name, a tiny uppercase tagline and a rust arrow link.

**Consumer provides:** `image`, `title`, optional `icon`, `tagline`, `linkLabel`, `href`.

- Seven across on desktop, in this order: Fresh Mushrooms, Hand Crafted Tinctures, Grow Kits, Recipes, Workshops, Liquid Cultures, More.
- Link labels are verbs + noun in caps (“SHOP FRESH →”, “SEE EVENTS →”).
