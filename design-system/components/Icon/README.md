# Icon

Thin-line pictograms (1.5px stroke on a 24px grid, round caps) used for trust badges, benefits, category tiles and band pillars.

**Consumer provides:** `name` (one of `SamuraiFungi.Icon.names`), optional `size` (default 24) and `strokeWidth`, `title` when the icon carries meaning on its own.

- Icons inherit `currentColor`: set the colour on the parent (`ink` on paper, `on-band` or `gold` on bands).
- Use 36–52px with `strokeWidth` 1.2–1.25 for feature and benefit rows; 24px with 1.5–2 for UI chrome.
- Do not fill icons or put them in coloured chips. On bands they may sit in a gold ring (`InkBand` pillars).
