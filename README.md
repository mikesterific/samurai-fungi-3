# Samurai Fungi

Design work for the Samurai Fungi storefront.

- `assets/` — the source page mockups (Home, MyPothecary Extracts category, Lion's Mane product).
- `design-system/` — the Samurai Fungi design system built from those mockups: tokens (`tokens.json`), brand book (`README.md`), React components (`components/bundle.js`, `bundle.css`, `index.d.ts`, one folder per component with guidelines and a preview), and logo, product, category and icon assets.

The live, editable version is the design system artifact on claude.ai: https://claude.ai/artifact/YApU2PqBSPNAhW1gdtRrE1 (private to its owner unless shared).
